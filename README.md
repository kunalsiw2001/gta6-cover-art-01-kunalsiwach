Sunset Heist Cover Studio turns your own photos into a multi-panel poster cover: pick a layout (hero + strips, 2 x 2 grid, three vertical panels, or a single hero), fill each panel with a photo from your machine or a bundled sample, drag to crop and position each one, write a bold caption, pick a colour grade (Sunset, Neon Nights, Noir, Palm), and export a PNG in 1080 x 1080, 1080 x 1350 or 1920 x 1080. It runs entirely offline in a desktop browser — photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
